# 🛠️ Análise de KPIs e Chamados de Suporte Técnico em TI (SQL)

## 📌 Visão Geral
Este repositório contém a modelagem e consulta de dados para gestão de um Helpdesk / Service Desk de TI. O objetivo é analisar o desempenho operacional do atendimento através de indicadores de resolução de incidentes.

## 📊 Indicadores Analisados (KPIs de TI)
- **Volume Total de Incidentes:** Distribuição por categoria (Hardware, Software, Redes).
- **Tempo Médio de Resolução (TMR):** Cálculo em horas do tempo decorrido entre a abertura e a conclusão dos chamados.
- **Distribuição por Prioridade:** Identificação de gargalos operacionais em demandas críticas.

## 📂 Arquivos no Repositório
- `analise_suporte.sql`: Script SQL contendo DDL (criação da tabela), DML (carga de dados) e DQL (consultas de KPIs).
